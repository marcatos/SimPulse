Decisions made
- Hybrid UX “C”: system sheet on first list load; UserDefaults `com.marcatos.SimPulse.healthAuthPrompted` prevents re-prompt on refresh.
- Port `HealthAuthorization` tracks “prompted”, not read authorization (HealthKit does not expose reliable read status).
- Empty `.needsHealthAccess` covers denial, restriction, and truly no Sim Racing workouts — same UI by design.
- HealthKit types aligned with Watch: share `workoutType`, `activeEnergyBurned`; read `workoutType`, `activeEnergyBurned`, `heartRate`.
- Open Settings opens app Settings only; user navigates to Health manually.
