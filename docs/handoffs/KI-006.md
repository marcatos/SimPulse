Decisions made
ADR 0014 accepted. Pairing issues a random 32-byte opaque token once; wire format is lowercase hex. Bridge stores only SHA-256 of raw token bytes and uses fixed-time comparison. DeviceId-only, missing/wrong tokens, revoked devices, and legacy rows without a hash are untrusted. Legacy clients must re-pair. IOS-005 must store the plaintext token in Keychain and send it on hello.
