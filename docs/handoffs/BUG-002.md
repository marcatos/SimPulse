## Decisions made

- File logger is a MEL `ILoggerProvider` in Core (no extra NuGet). Daily `bridge-yyyyMMdd.log` under LocalAppData/SimPulse/logs; `SIMPULSE_LOG_DIR` overrides; `SIMPULSE_LOG_FILE=0` disables.
- Tray ready wait timeout is 5s. Failure/timeout → ConsolePairingUx + ERROR; late NotifyIcon is disposed.
- Last PIN is stored on `ShowPin`. **Show current PIN** calls `RedisplayLastPin()` and does not call `BeginPairingWindow` or log the PIN.
- NotifyIcon tooltip is not cleared on BalloonTipClosed.
- Pair new device exceptions are caught in the presenter and the WinForms menu handler.
