# iOS app (SimPulse)

Apple project generation pending macOS/Xcode environment.

Swift sources here are a specification so Watch/iPhone work can start on a Mac without inventing `project.pbxproj` by hand. See [ADR 0009](../../docs/adr/0009-apple-project-generation.md).

Do not claim these targets compile until an Xcode project exists and `scripts/test-ios.sh` has been run on macOS.
